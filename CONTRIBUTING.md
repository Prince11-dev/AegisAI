# Contributing to AegisAI

First off, thank you for considering contributing to AegisAI!

Our goal is to build a production-quality, open-source Enterprise AI Platform that demonstrates modern software engineering, AI engineering, and cloud-native development practices.

---

## Code of Conduct

Please read the [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before contributing.

---

## Development Workflow

1. Fork the repository.
2. Create a feature branch.

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes.
4. Add or update tests.
5. Ensure all checks pass.
6. Commit using Conventional Commits.
7. Open a Pull Request.

---

## Branch Naming

Examples:

```
feature/authentication

feature/rag-engine

feature/github-agent

feature/frontend-dashboard

bugfix/login

docs/readme-update
```

---

## Commit Convention

We use Conventional Commits.

Examples:

```
feat(auth): implement JWT authentication

fix(api): resolve validation error

docs(readme): improve installation guide

test(rag): add embedding tests

refactor(router): simplify provider selection

chore(ci): add GitHub Actions workflow
```

---

## Coding Standards

- Follow PEP 8
- Use type hints
- Write meaningful docstrings
- Keep functions small and focused
- Prefer composition over inheritance
- Avoid unnecessary complexity

---

## Testing

Every new feature should include:

- Unit tests
- Integration tests (when applicable)
- Documentation updates

---

## Pull Request Checklist

Before submitting a Pull Request:

- [ ] Code compiles successfully
- [ ] Tests pass
- [ ] Documentation updated
- [ ] No unnecessary files committed
- [ ] Commit messages follow conventions

---

## Reporting Issues

Please include:

- Operating System
- Python Version
- Steps to Reproduce
- Expected Behavior
- Actual Behavior
- Screenshots (if applicable)

---

## Questions

If you have questions or ideas, open a GitHub Discussion or Issue.

Happy coding!
